# My little corner

A cozy desktop portfolio using your twilight desk artwork. The website is in `dist/`; no build or installation is required. Open `dist/index.html` in your browser to view it.

## Personalize

- Edit the `pages` object in `dist/app.js` to add your biography, projects, resume, and contact details. The current personal content is explicitly placeholder text.
- Edit the welcome message and sticky note in `dist/index.html`.
- Adjust colors, placement, and responsive styles in `dist/styles.css`.
- The supplied background is copied to `dist/assets/twilight-desk.png`.

Features: keyboard-accessible desktop icons, modal app windows, minimize/restore, Start menu search, local time, a small command terminal, and optional synthesized ambient sound. The layout adapts for phones and honors reduced-motion preferences. Google Fonts are optional; system font fallbacks work offline.
